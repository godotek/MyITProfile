## 📖 README ДОКУМЕНТАЦИЯ ПО РЕПОЗИТОРИЮ MyITProfile

**Наш проект - личный кабинет студента, в котором все устроено максимально удобно для студента (просмотр различной информации).**

---

## О проекте

**Ключевые возможности:**
- Просматривать расписание
- Узнавать оценки по занятиям
- Заказывать обеды
- Узнавать последние новости учебного заведения

---

## Как запустить

### Требования
- Скачать ZIP архив GitHub проекта
- Разархивировать и перейди в MyITProfile/front/index.html
- Открыть страничку проекта

## Используемый стэк технологий при разработке 

- HTML & CSS : вёрстка наружнего вида сайта
- JavaScript : логика проекта, работа его функциональности.
- Figma : разработка дизайн макета для сайта
- Kanban (Kaiten / МосТрек) : рспределение задач для команды
- Прочее ПО : написание документации, создание ER диаграм и др.
